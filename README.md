# Programming Curiosity Challenge 🚀

This repository is not about memorizing programming answers.

It is about understanding **why, what, how, where, when, who, and what if** behind the technology we use every day.

Every question is an opportunity to go one level deeper. Don’t just learn code. Understand what happens behind the code.

## How to take the challenge

Don’t search for the answers immediately. Pick questions, discuss them with your team, make your own assumptions, and then investigate to find the real answer.

You do not need programming experience to begin. Start with the questions that make you curious, follow the learning path below, and use the linked guides as you explore.

## Ask seven questions whenever you learn something

- **WHY?**
- **WHAT?**
- **HOW?**
- **WHERE?**
- **WHEN?**
- **WHO?**
- **WHAT IF?**

For example, don’t stop at “I learned MongoDB.” Ask:

- What is MongoDB?
- Why do we use it?
- How does it store data?
- Where is the data physically stored?
- When should I choose MongoDB?
- Who uses it in the industry?
- What if MongoDB goes down?

A good programmer doesn’t just learn answers. **A good programmer develops better questions.**
