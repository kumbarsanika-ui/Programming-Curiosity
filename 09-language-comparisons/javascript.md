# JavaScript

JavaScript is a general-purpose language especially associated with interactive web pages. Browsers provide a JavaScript engine, so code can respond to clicks, update a page, and communicate with web services. JavaScript is also used on servers and in other environments.

```javascript
const names = ["Ada", "Lin"];
for (const name of names) {
  console.log(`Hello, ${name}!`);
}
```

JavaScript is dynamically typed. It supports several programming styles and has built-in asynchronous features useful for coordinating network and other input/output work. TypeScript adds a static type-checking layer and is commonly converted to JavaScript before execution.

## Strengths and trade-offs

JavaScript's browser support makes it essential for much web development, and using it on both client and server can simplify sharing some code. The language and ecosystem are broad, so project conventions and tooling matter. A browser environment and a server environment also provide different APIs even when both run JavaScript.
