# Python

Python is a general-purpose programming language known for readable syntax and a large collection of libraries. It is used in scripting, automation, web services, education, scientific computing, and data work.

```python
for name in ["Ada", "Lin"]:
    print(f"Hello, {name}!")
```

Python uses indentation to mark blocks of code. It is dynamically typed: a value has a type, but a variable name is not usually declared with a fixed type. Python implementations commonly run source through a bytecode virtual machine, though implementation details differ.

## Strengths and trade-offs

Python's syntax can make ideas quick to express, and its ecosystem is broad. It may use more memory or run slower than a carefully optimized native program for some workloads. Libraries written in other languages and alternative Python implementations can change performance characteristics.

Python is a good first language for many learners, but the best choice depends on what you want to build. Compare it with [JavaScript](./javascript.md) and [Java](./java.md).
