# Java

Java is a general-purpose, statically typed programming language used in server software, business systems, Android development, and many other areas. It is designed to run on the Java Virtual Machine (JVM).

```java
String name = "Ada";
System.out.println("Hello, " + name + "!");
```

Java tools normally compile source code into bytecode, which a JVM can execute. The JVM handles many runtime tasks, including memory management through garbage collection. Static type checking catches certain kinds of mismatches before code runs.

## Strengths and trade-offs

Java has mature tooling, a large ecosystem, and useful features for organizing larger applications. Its syntax can be more explicit than that of some scripting languages, and a Java application needs a compatible runtime environment. JVM implementations and frameworks have their own configuration and learning requirements.

Language versions and JVM distributions differ, so projects specify the environment they support. Compare with [Python](./python.md) and [JavaScript](./javascript.md).
