# Cloud

Cloud computing means using computing resources—such as servers, storage, databases, and networking—provided over a network, commonly by a cloud provider. Instead of owning every physical machine, a team can provision resources when needed.

## Service models

Infrastructure as a Service (IaaS) provides flexible computing resources that the customer configures. Platform as a Service (PaaS) manages more of the runtime and deployment environment. Software as a Service (SaaS) provides a complete application for people to use. The boundaries are not always sharp.

## Benefits and trade-offs

Cloud services can make it easier to start small, automate provisioning, and reach users in multiple regions. They still require configuration, monitoring, backups, and security. Costs can grow unexpectedly, and a service may depend on one provider's features or availability.

“The cloud” is not magic: software still runs on physical computers in data centers. The provider manages some layers, while the customer remains responsible for others. The shared responsibility model differs by service.

## Deploying an application

Deployment moves a tested version of an application into an environment where users can access it. A deployment process may build the code, configure services, run database migrations, and monitor the rollout. See [Servers](./server.md) and [Scaling](./scaling.md).
