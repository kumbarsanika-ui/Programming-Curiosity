# Server

A server is a computer or program that provides a service to other programs, called clients. The word can describe the hardware, the software, or the role it performs.

## Requesting a service

A web server listens for network requests and sends responses. It may serve files directly or pass work to an application that applies business rules, accesses a database, and builds a response. A single physical computer can host many services, and a service can run across many computers.

## Keeping a service reliable

Servers need operating systems, network access, configuration, updates, monitoring, and appropriate security controls. They may need to restart after failures, limit abusive traffic, and report errors so operators can diagnose issues.

## Local and remote

During development, a server can run on a programmer's own computer. In production, the service is usually deployed to infrastructure that users can reach. That infrastructure may be managed directly or provided by a [cloud](./cloud.md) provider.

The client-server model appears throughout the internet. A browser is a client when it requests a page; the website's server processes that request. See [HTTP](../04-internet/http.md).
