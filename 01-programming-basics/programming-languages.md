# Programming languages

A programming language is a structured way for people to write instructions that tools can translate or execute. Languages provide rules for spelling expressions, combining them into larger programs, and describing data.

## Why are there many?

Different languages make different trade-offs. Some emphasize concise syntax, some provide strong tools for large applications, and some are designed for a particular environment. Python is often used for scripting and data work; JavaScript is widely used in browsers; Java is common in many large server and Android systems. These are tendencies, not limits.

Languages also differ in how they represent values, catch mistakes, manage memory, and run programs. No single language is best for every task. The [language comparisons](../09-language-comparisons/python-vs-javascript-vs-java.md) explore a few common choices.

## Syntax and meaning

Syntax is the language's writing rules. For example, Python uses indentation to group a block:

```python
if temperature > 25:
    print("Warm")
```

The meaning of the code is what the language says those instructions do. Code can have valid syntax but still express the wrong logic, just as a grammatically correct sentence can be factually wrong.

## From source code to action

Programmers usually write human-readable source code. A compiler or interpreter, often together with other tools, translates that code into operations the computer can perform. Languages can use a mixture of compilation and interpretation; these terms describe approaches, not an absolute division between languages.

## The key idea

A language is a tool for expressing ideas precisely. Once you understand concepts such as values, decisions, repetition, and functions, much of that understanding transfers between languages even when the syntax changes.
