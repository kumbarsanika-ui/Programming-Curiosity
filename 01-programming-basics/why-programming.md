# Why programming?

Programming is the practice of describing steps a computer can carry out. A program might calculate a total, show a web page, control a robot, or help people communicate. The computer follows instructions very quickly and consistently, but the instructions must be expressed in a form it can process.

## Programs solve problems

Imagine repeatedly adding the prices in a shopping basket. You could do it by hand, or write a small program that adds every price and displays the result. The program turns a repeatable set of steps into an automated tool.

Programs are also useful when a task is too large or fast for a person alone: searching millions of records, coordinating a video call, or modeling the weather. People still decide what problem to solve and how a result should be used.

## Programming is more than typing code

Good programming includes understanding the problem, breaking it into smaller parts, choosing suitable data and tools, writing instructions, testing them, and improving them when requirements change. Bugs are mistakes or unexpected conditions in a program; finding and fixing them is a normal part of the work.

## A small example

In Python, `total = 3 + 4` asks the computer to add two numbers and associate the result, `7`, with the name `total`. A later instruction could display it. The details of names and values appear in [Variables](../02-variables-and-memory/variables.md).

## The key idea

A computer is a general-purpose machine. Programs give it specific behavior. Learning to program means learning to express a problem clearly enough that a computer can help solve it.
